# MarinBio AgritechSolutions website

This repository deploys the complete MarinBio multi-page corporate website. During the Vercel build, `site.tar.gz` is extracted at the project root and served as a static HTML, CSS and JavaScript website.

The release includes 27 HTML pages, eight individual solution pages, a dedicated BioVitalix B+ page, technology, projects, research, insights, gallery, contact and quotation routes.
