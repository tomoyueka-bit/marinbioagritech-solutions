# MarinBio Agritech Solutions Ltd — Corporate Website

Production multi-page website for MarinBio AgritechSolutions Ltd, a Kenyan biotechnology, circular bioeconomy and climate-smart agriculture company.

## Website scope

- Dedicated BioVitalix B+ page and top-level navigation item
- Solutions overview plus eight individual solution pages
- Technology, projects, research, insights, gallery, contact and quotation pages
- Responsive navigation and services mega-menu
- Accessible homepage slider, filterable gallery and FAQ components
- Responsible scientific-claims language and product disclaimer
- SEO files, security headers and Vercel deployment configuration

## Deployment

The complete static site is stored as `site.tar.gz`. Vercel runs `npm run build`, extracts the website into `dist`, and publishes that directory.

## Content safeguards

Unverified claims, client names, impact statistics, research outcomes and company contact information have not been fabricated. The official MarinBio logo and verified administrative contact details should replace the temporary wordmark and unpublished contact placeholders when supplied.
